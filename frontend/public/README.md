# Static assets

`logo-placeholder.svg` is a neutral placeholder wordmark. The original assets
(operator logo, photo of an employee) are not part of this release — trademark
and personality rights.

To brand the UI, replace `logo-placeholder.svg` and adjust the two usages:

- `app/_components/LoginScreen.tsx`
- `components/TopBar.tsx`

The user avatar in `app/globals.css` (`.user-chip .avatar`) is a gradient with
the user's initials, not an image.
